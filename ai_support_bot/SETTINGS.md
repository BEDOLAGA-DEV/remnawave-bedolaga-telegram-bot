# Настройки поддержки SligVPN

Готовый системный промпт для поля админки: [SYSTEM_PROMPT.txt](SYSTEM_PROMPT.txt).
Актуальные правила сервиса код добавляет и к ранее сохранённому промпту. При вставке полного нового промпта повторного блока не будет.

| Поле админки | Значение |
|---|---|
| Модель ИИ | `gpt-4o-mini` |
| Модель эмбеддингов | `text-embedding-3-small` |
| Макс. токенов ответа | `600` |
| Температура | `0.2` |
| Количество примеров (Top K) | `3` |
| Минимальная релевантность | `0.35` |
| Сообщений в контексте | `8` |
| Лимит истории | `100` |
| Сообщений на пользователя в день | `0` |
| Анализ фото | `1` |
| Данные Remnawave | `1` |

Это стартовый профиль для проверки на реальных обращениях, а не измеренный оптимум. Модели сохранены прежними; переиндексация базы знаний не требуется. Порог релевантности проверяйте по вашим тикетам: при пропуске полезных примеров можно снизить до `0.30`.

Эти значения заданы в коде и `.env.example`. Уже сохранённые параметры админки и существующий `.env` имеют приоритет: для работающей установки выставьте профиль в разделе ИИ-поддержки. Изменения кода вступят в силу после пересборки и перезапуска сервиса. В рамках этой доработки рабочая БД настроек и запущенные сервисы не изменялись.

Для экономии используются три примера до 1200 символов каждый, восемь последних сообщений и сводка каждые три хода (до 220 токенов). Кеш ответа учитывает актуальные данные пользователя, промпт и параметры генерации. Короткие реплики без фото пропускают поиск по базе и чтение персональных данных. Дневной лимит `0` оставляет поддержку без искусственного ограничения; троттлинг сохраняется.

Remnawave включайте при настроенных URL и токене панели. Фото анализируются только при включённом параметре и наличии изображения; качество распознавания чеков не подтверждает факт зачисления платежа.

## Проверка с тестером

- «Как подключиться?» — инструкции для сайта и бота; при известном канале только для него.
- «Какие приложения для iPhone?» — Incy и клиенты iOS, без Hiddify/FoXray и ненужной просьбы о скриншоте.
- «Не работает VPN» — короткая первичная диагностика; «всё это уже пробовал, не помогло» — передача обращения.
- «Пишу насчёт сотрудничества» — отдельный текст благодарности и передача команде.
- «Не пришли деньги» — чек платежа, неизвестный канал покупки и при необходимости email; передача обращения без повторной оплаты.
- «Пополнил баланс, подписка не продлилась» — различение пополнения и продления, проверка доступных данных, путь к ручному продлению.
- Лимит устройств `0` — отсутствие ограничения, без совета удалить устройства.
- Смена темы и короткие уточнения — сохранение контекста без повторения решённых вопросов.

Автотесты проверяют сборку контекста, кеш, навигацию и доставку эскалации с подменённым ответом модели. Поведение самой модели нужно дополнительно проверить этими репликами на рабочей базе знаний.
