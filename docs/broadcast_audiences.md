# Аудитория рассылки

В кабинете Telegram и Email рассылки имеют отдельные наборы условий. Каждая строка
содержит поле, сравнение и значение. Между строками выбирается `И` или `ИЛИ`;
условия вычисляются строго сверху вниз. Строк можно добавить сколько угодно.

Доступны статус и тип подписки, тариф, использованный трафик (`0`, больше или
меньше заданного числа ГБ), даты регистрации, последней активности и окончания
подписки, источник и способ регистрации, история оплат. Для Telegram можно
выбрать пользователя по любой части Telegram ID или ника; для Email — по любой
части адреса. Email также поддерживает промогруппу. Выбранный пользователь
сохраняется в условии по внутреннему ID.

`Равно` и `Не равно` применяются к результату отдельного условия. Например,
`Тариф не равно X` означает, что у пользователя нет действующей подписки с
тарифом X. `Статус подписки: истекла` выбирает тех, у кого нет действующей
подписки. Даты поддерживают сравнения «до», «после» и «между».

Кабинет запрашивает счётчик и постраничный список через
`POST /cabinet/admin/broadcasts/audience/preview`. Поиск пользователя для
условия выполняется через `GET /cabinet/admin/broadcasts/audience/users`.
Предпросмотр ничего не отправляет. При создании рассылки правила сохраняются
в `broadcast_history.audience`; перед доставкой получатели определяются заново
по текущим данным и с учётом настроек уведомлений.

Миграция `0129_broadcast_audience` добавляет колонку `audience` после
`0128_dpichecker_actions`. Backend следует развернуть до frontend, поскольку
новая форма использует оба маршрута аудитории и новое поле запроса рассылки.
