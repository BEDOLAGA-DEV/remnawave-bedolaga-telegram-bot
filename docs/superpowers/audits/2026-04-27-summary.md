# Pre-Release Security Audit — Summary

**Date:** 2026-04-27
**Branch:** `claude/audit-2026-04-27`

This audit covered three phases of cross-cutting bug-class review.

## Phase 1 — Static sweep (`docs/superpowers/audits/2026-04-27-phase1-sweep.md`)

Patterns P1-P11 across `app/`, `bedolaga-cabinet/src/`, `migrations/`. 73 hits triaged: 6 quick-fixed, 32 queued for Phase 2, 0 false-positives, 35 accepted with rationale.

Highlights: P7 raw-grep flagged 32 unlocked balance mutations — Phase 2 verified all but 3 already lock via wrapper-level helpers. P9 surfaced refresh-token in localStorage (queued, eventually addressed in Phase 2 finding #5). P11 surfaced 4 missing FK indexes on shipped migrations — queued for follow-up migration.

## Phase 2 — Targeted deep dive (`docs/superpowers/audits/2026-04-27-phase2-deepdive.md`)

22 findings across 3 risk classes:
- (a) Money-path race conditions: 3 findings, 3 patches landed.
- (b) Auth bypass / IDOR / JWT: 3 findings, 2 patches, 1 deferred (JWT-secret startup fail-fast).
- (c) Webhook signature verification: 16 providers audited, all verify correctly. 2 deferred items: cloudpayments silent-skip when secret unset; platega header-based shared secret (not body-bound).

Severity breakdown: 0 critical / 4 high / 3 medium / 1 low.

Patches landed:
- `app/handlers/stars_payments.py` — refund TOCTOU + atomic marker.
- `app/database/crud/achievement.py` — lock_user_for_update in check_and_unlock_all.
- `app/services/promocode_service.py` — lock + rollback on early return.
- `app/cabinet/routes/media.py` — IDOR fix for download_media.
- `app/cabinet/routes/auth.py` — refresh-token rotation.

## Deferred items requiring follow-up

1. **CABINET_JWT_SECRET fallback to BOT_TOKEN** — startup-time fail-fast wiring needed (Phase 2 row #6).
2. **CloudPayments webhook silent-skip** — when `CLOUDPAYMENTS_API_SECRET` is unset, signature verification is bypassed (Phase 2 row #21). Same fix shape as #6.
3. **Platega header-based secret** — not body-bound; defer pending provider coordination (Phase 2 row #12).
4. **Missing FK indexes on shipped migrations 0003 / 0011 / 0067** — follow-up migration to add indexes (Phase 1 P11).
5. **Refresh-token device fingerprint not re-recorded on rotation** — minor tightening, post-MVP.
6. **`achievement.py::check_and_unlock_all` holds FOR UPDATE across Telegram bot I/O** — restructure to defer notifications post-commit (Phase 2 review observation, non-blocking).

## Audit outcome

Branch ready for review and merge. All critical/high findings either patched in-branch or explicitly deferred with rationale.
